Detailed Description

Utilities needed for a particle in cell code.

Defines graphs for use in Particle In Cell (PIC) codes.

Enumeration Type Documentation

◆ model

enum pic::model

Model for coulomb scattering operators.

Enumerator
hinton 

From Hinton 1983 EQ 92 and T.S. Chen 1988 EQ 50.

chen 

From T.S. Chen 1988 Report EQ 57 commonly used for NBI.
