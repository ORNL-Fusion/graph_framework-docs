Detailed Description

template<jit::float_scalar T, bool SAFE_MATH = false, class BASE_NODE = leaf_node<T, SAFE_MATH>, size_t N = 1>
class graph::no_derivative< T, SAFE_MATH, BASE_NODE, N >

Nodes without derivatives.

Some functions have no derivative. This can be used as a base class to case a compile error if a derivative node is attempted.

Template Parameters
TBase type of the calculation.
SAFE_MATHUse Safe Math operations.
BASE_NODEBase code to subclass from.
NNumber of sub-nodes.
